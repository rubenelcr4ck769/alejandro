Explicación

Para este formulario elegimos el método POST en lugar de GET, ya que se están capturando datos sensibles como la contraseña y no queremos que viajen visibles en la URL del navegador. El atributo action apunta a la carpeta php del servidor, al archivo insertar_cv.php, que sería el encargado de procesar la información en el backend. Usamos el atributo maxlength para limitar el nombre a 30 caracteres, los apellidos a 80 y la contraseña a 10, tal como lo pedía el ejercicio. Para el CURP se definió un patrón de 18 caracteres alfanuméricos, que es la longitud real de este documento en México. El checkbox del boletín de novedades se dejó marcado por defecto usando el atributo checked. Finalmente se agregaron los tres botones solicitados: el campo de tipo file para subir la fotografía, un botón submit para guardar los cambios y un botón reset para borrar todo lo que el usuario haya introducido.
