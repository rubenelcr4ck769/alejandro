Práctica 6: Integración de HTML y CSS

Explicación

Para esta última práctica, el reto fue consolidar e integrar absolutamente todo lo aprendido en los ejercicios anteriores para dar vida a un sitio web completo y con un aspecto mucho más formal. Utilizamos las etiquetas de HTML para armar todo el esqueleto y el contenido, incluyendo títulos, imágenes con img y enlaces de navegación con a. Lo interesante fue usar el archivo practica6.css para tomar el control total de la maquetación en pantalla. En lugar de que todo saliera hacia abajo en una sola columna, acomodamos los elementos de forma estratégica para dividir la interfaz en áreas comunes de un sitio profesional: un encabezado en la parte superior, un menú para moverse por la web, el bloque para contenido principal, una barra lateral para información extra y el clásico pie de página al final. Esto nos dejó claro cómo HTML y CSS trabajan en equipo para lograr páginas web funcionales y bien organizadas.
