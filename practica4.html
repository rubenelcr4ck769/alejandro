Práctica 4: Formularios HTML

Explicación

En esta práctica nos enfocamos en crear un puente de comunicación directa entre el usuario y nuestra página web utilizando la etiqueta principal form. Aprendimos que la etiqueta input es fundamental y versátil, ya que cambiando su tipo (type) podemos capturar información de muchas maneras: usamos text para nombres o datos simples, password para ocultar de la vista los caracteres confidenciales, y botones tipo radio o checkbox para cuando el usuario debe elegir entre una o varias opciones prefijadas. Además de estos campos, añadimos la etiqueta textarea que es perfecta para cuando la gente necesita escribir comentarios o textos más largos, y el combo de select con option para armar un menú desplegable muy limpio. Todo esto se complementa con botones especiales para enviar la información recopilada o limpiar por completo el formulario para volver a empezar.
