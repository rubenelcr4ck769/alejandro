Explicación

En esta práctica trabajamos con dos formas distintas de recorrer estructuras de datos en JavaScript. El bucle for...in recorre las propiedades enumerables de un objeto o, en el caso de un arreglo, sus índices (0, 1, 2, 3...), por eso en el primer ejemplo la variable x toma el valor del índice y hay que usar numbers[x] para obtener el dato real. En cambio, el bucle for...of recorre directamente los valores de un objeto iterable, ya sea un arreglo de elementos como los coches, o incluso una cadena de texto carácter por carácter, como se ve en el segundo ejemplo con el nombre "Sarai Martin". En ambos casos se va concatenando el resultado en una variable de texto y al final se inyecta en el documento usando innerHTML sobre un elemento con id específico. Por último, el cuarto ejemplo usa el objeto Date de JavaScript para obtener la hora, los minutos y los segundos actuales del sistema con getHours, getMinutes y getSeconds, y aplica una validación con if para anteponer un cero cuando el valor es menor a 10, logrando así un formato de reloj de dos dígitos como 09:05:03.
