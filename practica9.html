Explicación

En esta práctica el objetivo fue armar la maquetación clásica de un sitio web usando únicamente HTML y CSS, sin tablas ni frames. Definimos un marco principal con id conteiner que envuelve todo el sitio, un marco superior con id header para el título naranja, y dentro del cuerpo dividimos el espacio en tres columnas usando flexbox: una columna izquierda con id izquierda que contiene la lista de hipervínculos, una columna central que muestra el título y subtítulo del contenido, y una columna derecha con id derecha pintada de amarillo claro para simular un espacio de anuncios o imágenes. Finalmente, el marco inferior con id footer cierra el diseño con el pie de página del sitio. Esta forma de maquetar con divs identificados por id es la base de cómo se estructuran los sitios web profesionales antes de pasar a frameworks más modernos.
