Práctica 3: Tablas en HTML

Explicación

En esta práctica aprendimos a acomodar datos en filas y columnas usando la etiqueta table. Para armarla, usamos tr para crear cada fila y td para meter el contenido dentro de las celdas. También usamos th para poner títulos llamativos en la parte de arriba de la tabla y el atributo border para que las líneas divisorias se alcancen a ver.
