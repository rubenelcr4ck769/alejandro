Práctica 1: Etiquetas básicas de HTML





Explicación

En esta primera práctica vimos la estructura más básica de una página web. Aprendimos a usar los h1 h6 para poner títulos de diferentes tamaños e importancia, y la etiqueta p para separar los textos en párrafos. También usamos la etiqueta a para crear enlaces a otros sitios y la etiqueta img para meter imágenes usando su atributo src para buscar el archivo.
